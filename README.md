# 🚌 Bus Sniper Bot - Web Version

Automatic bus ticket booking for 1337 bus system.

## 🚀 Quick Start

1. **Install dependencies:**
```bash
npm install
```

2. **Run locally:**
```bash
npm run dev
```

3. **Open** http://localhost:3000

## 📦 Deploy to Vercel

1. Push to GitHub
2. Import on Vercel
3. Deploy!

## 🎯 How to Use

1. Get your token from browser cookies (`le_token`)
2. Enter target city (e.g., "Casablanca")
3. Enter departure time (e.g., "18:00")
4. Click "Start Sniping"
5. Watch the magic happen! ✨

## ✨ Features

- 🎯 Real-time monitoring
- 🔥 Aggressive booking mode
- 📊 Live statistics
- 🎨 Modern UI with Tailwind CSS
- 🚀 Serverless architecture

## 🛠️ Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Server-Sent Events (SSE)
